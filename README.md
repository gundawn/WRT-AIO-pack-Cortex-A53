Удобный скрипт для подключения по SSH
Одной командой:
-обновляете список апдейтов системных пакетов
-обновляете системные пакеты в один клик, вместо установки из интерфейса поштучно, ставите русик
-разлочка гитхаба через домены hosts
-устанавливаете тему оформления
-качается основной компонент NetShift вне его установки, свежий билд под нужную архитектуру
-устанавливаете готовый менеджер NetShift с русиком

Останется лишь настроить сетку, тему и сам NetShift за пару минут, без лишнего
Смогу делать бэкап- скрипт быстро устареет, особенно если найду сервер с vless
