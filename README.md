**<h1>Удобный скрипт для подключения по SSH<h1>**

Одной командой:

-обновление списка апдейтов\дров системных пакетов

-обновление системных пакетов в один клик, вместо установки из интерфейса поштучно, русификатор (нативный)

-установка темы оформления

-установка основного компонента NetShift вне установки самого NetShift, чтобы не поставилась старая версия по дефолту, свежий билд под нужную архитектуру

-установка готового менеджера NetShift с русиком

Останется лишь настроить сетку, тему и сам NetShift за пару минут, без лишнего. Смогу делать бэкап- скрипт быстро устареет, особенно если найду сервер с vless для быстрой настройки. Если получится экспортировать настройки темы и иконок- вообще счастлив буду.




**<h2>Системные требования:<h2>**

OpenWRT

Не менее 30 мб свободной памяти (лучше чистая установка с нуля)

Отсутствие VPN, DNS и DoH\DoT (опять же лучше с нуля с готовым интернетом)

Высокая производительность роутера


**<h3>Исполняемый скрипт в SSH:<h3>**

  wget -O - https://raw.githubusercontent.com/xaxaaxaaa-hash/WRT-AIO-universal/main/install.sh | sh

Копируем целиком от и до, исполняем, следуем инструкции. "aurora-shadcn" не ставим.
