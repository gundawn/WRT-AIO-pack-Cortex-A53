Удобный скрипт для подключения по SSH

Одной командой:

-обновляете список апдейтов системных пакетов

-обновляете системные пакеты в один клик, вместо установки из интерфейса поштучно, ставите русик

-разлочка гитхаба через домены hosts

-установка темы оформления

-установка основного компонента NetShift вне его установки, свежий билд под нужную архитектуру

-установка готового менеджера NetShift с русиком

Останется лишь настроить сетку, тему и сам NetShift за пару минут, без лишнего. Смогу делать бэкап- скрипт быстро устареет, особенно если найду сервер с vless для быстрой настройки. Если получится экспортировать настройки темы и иконок- вообще счастлив буду.

Системные требования:

Open\Immortal\VERDE WRT 25.0+

Не менее 30 мб свободной памяти (лучше чистая установка с нуля)

Отсутствие VPN, DNS и DoH\DoT (опять же лучше с нуля с готовым интернетом)

Архитектура Cortex-A53 (например Xiaomi AX3000T mtk, Redmi AX6 и др.)

Исполняемый скрипт в SSH:

  wget -O - https://raw.githubusercontent.com/xaxaaxaaa-hash/WRT-AIO-pack-Cortex-A53/main/install.sh | sh

Копируем целиком от и до, исполняем, следуем инструкции. "aurora-shadcn" не ставим.
