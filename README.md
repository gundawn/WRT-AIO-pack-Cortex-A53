OpenWrt AIO Universal Installer

Универсальный установщик для OpenWrt, который позволяет подготовить роутер к дальнейшей настройке одной командой.

Возможности

Скрипт автоматически выполняет:

* обновление списка доступных пакетов;
* обновление установленных системных пакетов;
* установку нативной русской локализации LuCI;
* установку темы оформления Aurora;
* установку актуальной версии sing-box-extended;
* автоматический подбор пакета sing-box-extended под архитектуру роутера;
* установку NetShift вместе с русской локализацией.

После выполнения скрипта останется только настроить:

* сеть;
* тему;
* sing-box-extended;
* NetShift.

Всё остальное выполняется автоматически.

Системные требования

* OpenWrt
* Не менее 30 МБ свободного места
* Рабочее интернет-соединение
* Доступ по SSH от имени root

Рекомендуется

Для чистой установки желательно использовать OpenWrt без предварительно настроенных:

* VPN;
* DNS-прокси;
* DoH;
* DoT;
* других сетевых туннелей и прокси.

Это не является строгим требованием, однако чистая система с уже работающим интернетом значительно снижает вероятность конфликтов при установке и первоначальной настройке.

Установка

Подключитесь к роутеру по SSH и выполните:

wget -O - https://raw.githubusercontent.com/xaxaaxaaa-hash/WRT-AIO-universal/main/install.sh | sh

Скрипт автоматически:

1. Проверит систему OpenWrt.
2. Определит архитектуру устройства.
3. Определит используемый пакетный менеджер.
4. Обновит списки пакетов.
5. Обновит установленные пакеты.
6. Установит русский язык LuCI.
7. Установит тему Aurora.
8. Найдёт актуальный релиз sing-box-extended.
9. Подберёт пакет под архитектуру устройства.
10. Установит sing-box-extended.
11. Установит NetShift.

Aurora

Во время установки Aurora не выбирайте aurora-shadcn.

Поддержка пакетных менеджеров

Скрипт автоматически определяет пакетный менеджер OpenWrt:

Пакетный менеджер	Формат пакета
apk	.apk
opkg	.ipk

Архитектура устройства также определяется автоматически.

Поэтому вручную искать подходящий пакет sing-box-extended не требуется.

После установки

После завершения установки необходимо самостоятельно настроить:

* сетевые интерфейсы;
* тему LuCI;
* sing-box-extended;
* NetShift;
* необходимые правила маршрутизации;
* списки и другие параметры NetShift.

Скрипт предназначен именно для автоматической подготовки системы и не заменяет индивидуальную настройку роутера.

Важная информация

Перед запуском на уже настроенном роутере рекомендуется сделать резервную копию конфигурации.

Для максимально предсказуемого результата рекомендуется использовать свежую установку OpenWrt с рабочим интернет-соединением.

Проект

Цель проекта — собрать основные действия по подготовке OpenWrt в один универсальный установщик:

Одна команда → готовая система для дальнейшей настройки.

Проект будет развиваться по мере необходимости: в дальнейшем возможны автоматический бэкап конфигурации, импорт настроек и другие дополнительные функции.
