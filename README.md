WRT AIO Universal

Универсальный установщик для OpenWrt.

Одна команда для первоначальной подготовки роутера: обновление системы, русская локализация LuCI, универсальное оформление, актуальный signbox-extended под нужную архитектуру, NetShift и задача на ежедневную перезагрузку в роутере для стабильности.

⸻

🚀 Быстрая установка

Подключитесь к роутеру по SSH от имени root и выполните:

```bash
wget -O - https://raw.githubusercontent.com/gundawn/WRT-AIO-universal/main/install.sh | sh
```

Скрипт автоматически определит:

* версию OpenWrt;
* архитектуру устройства;
* используемый пакетный менеджер (apk\opkg);
* необходимый формат пакета signbox-extended.

После запуска просто следуйте выводу в терминале.

⸻

✨ Что устанавливается


📦 Пакеты	Обновление списков и установленных пакетов в 1 клик, вместо установки поштучно
🇷🇺 LuCI	Русская локализация (нативная)
🎨 Aurora	Установка темы Aurora, ее конфигуратора и языкового пакета конфигуратора
⚡ signbox-ex	Актуальная версия под архитектуру устройства, должна устанавливаться перед NetShift, иначе подписки работать НЕ будут
🌐 NetShift	Установка NetShift
⏰ Cron       Задача в планировщике на ежедневную перезагрузку в 5:00 утра

signbox-extended

Скрипт получает информацию о последнем релизе и самостоятельно выбирает подходящий пакет.

Поддерживаются:

apk  → .apk

opkg → .ipk



В результате не требуется вручную искать и скачивать подходящую сборку.

⸻

🔧 Что делает скрипт

Порядок выполнения:

1. Проверка OpenWrt
       ↓
2. Обновление списков пакетов
       ↓
3. Обновление установленных пакетов
       ↓
4. Установка русского LuCI
       ↓
5. Установка темы
       ↓
6. Получение последнего signbox-extended
       ↓
7. Установка signbox-extended
       ↓
8. Установка NetShift
       ↓
9. Установка задачи в cron
       ↓
10. Итоговый отчёт

Каждый этап имеет собственный статус. Ошибка одного компонента не останавливает установку остальных.

⸻

📋 Требования

* OpenWrt
* SSH-доступ от имени root
* Рабочее интернет-соединение
* Не менее 30 МБ свободного места

Рекомендуется

Для первоначальной установки желательно использовать чистую систему с уже работающим интернетом.

Не рекомендуется запускать установщик поверх уже настроенных:

* VPN;
* DoH / DoT;
* DNS-прокси;
* сетевых туннелей;
* других систем маршрутизации трафика.

Скрипт создан для чистой системы.

⸻

⚠️ Aurora

При установке Aurora не выбирайте aurora-shadcn.

⸻

🛠 После установки

Установщик выполняет только подготовительную работу.

После завершения необходимо самостоятельно настроить:

* сеть;
* Aurora;
* NetShift;

Проект находится в разработке. Требуется делать импорт сохраненной темы, импорт начальных настроек NetShift, отметить ветки и авторов, которые используются в скрипте.
