OpenWrt AIO Universal Installer

Универсальный установщик для OpenWrt, который позволяет одной командой подготовить роутер к дальнейшей настройке.

Скрипт автоматически определяет пакетный менеджер (apk или opkg) и архитектуру устройства, после чего устанавливает и обновляет необходимые компоненты.

Возможности

Скрипт выполняет следующие действия:

* обновляет списки пакетов;
* обновляет установленные системные пакеты;
* устанавливает русский язык LuCI;
* устанавливает тему Aurora;
* определяет последнюю версию sing-box-extended;
* скачивает пакет sing-box-extended именно под архитектуру устройства;
* устанавливает sing-box-extended как системный пакет;
* устанавливает NetShift вместе с русской локализацией.

В результате после запуска остаётся только выполнить базовую настройку:

* сети;
* темы;
* sing-box-extended;
* NetShift.

Всё остальное скрипт делает автоматически.

Поддержка пакетных менеджеров

Скрипт автоматически определяет используемый пакетный менеджер:

* apk — современные версии OpenWrt;
* opkg — старые версии OpenWrt.

Для sing-box-extended автоматически выбирается соответствующий формат пакета:

* .apk для apk;
* .ipk для opkg.

Также автоматически определяется архитектура OpenWrt, поэтому вручную искать подходящий пакет не требуется.

Системные требования

* OpenWrt;
* не менее 30 МБ свободного места;
* рабочее интернет-соединение;
* доступ к SSH от имени root.

Рекомендуется

Для чистой установки желательно использовать свежую систему без предварительно настроенных:

* VPN;
* DoH/DoT;
* сторонних DNS-прокси;
* других сетевых прокси и туннелей.

Это не является обязательным требованием самого скрипта, но позволяет избежать конфликтов во время первоначальной установки и настройки NetShift.

Также желательно, чтобы роутер имел достаточный запас производительности и свободной памяти для работы всех устанавливаемых компонентов.

Установка

Подключитесь к роутеру по SSH и выполните:

wget -O - https://raw.githubusercontent.com/xaxaaxaaa-hash/WRT-AIO-universal/main/install.sh | sh

Скрипт автоматически:

1. проверит OpenWrt;
2. определит архитектуру и пакетный менеджер;
3. обновит списки пакетов;
4. обновит установленные пакеты;
5. установит русский язык LuCI;
6. установит Aurora;
7. загрузит актуальный sing-box-extended;
8. установит NetShift.

После завершения будет показан итоговый статус каждого компонента.

Важно: для установки Aurora используется официальный установщик проекта Aurora. Если установщик предлагает выбрать aurora-shadcn, выбирать его не нужно.

После установки

После выполнения скрипта потребуется самостоятельно настроить:

* сетевые интерфейсы;
* тему LuCI;
* sing-box-extended;
* NetShift;
* необходимые правила маршрутизации и списки.

Сама установка не заменяет настройку конкретной сети — она лишь максимально сокращает рутинную подготовку OpenWrt.

Почему AIO

Идея проекта — избавить от необходимости вручную:

* обновлять пакеты;
* искать русификатор;
* искать и устанавливать тему;
* искать подходящую сборку sing-box-extended;
* подбирать пакет под архитектуру роутера;
* отдельно устанавливать NetShift.

Одна команда — и система готова к дальнейшей настройке.

Примечание

Проект рассчитан прежде всего на чистую установку OpenWrt.

Перед использованием на уже настроенном роутере рекомендуется иметь резервную копию конфигурации.

Установщики сторонних компонентов загружаются непосредственно из их исходных репозиториев.
